WEBAPP — AVALIAÇÃO DE PACIENTES INTERNADOS

Arquivos:
- index.html: app principal.
- manifest.webmanifest: configuração para instalação como PWA.
- sw.js: funcionamento offline quando hospedado em HTTPS ou localhost.
- icon.svg: ícone do app.

Como usar:
1. Abra o arquivo index.html no navegador para usar localmente.
2. Para instalar no celular como app, hospede a pasta em HTTPS, por exemplo GitHub Pages, Netlify ou servidor institucional.
3. Depois de abrir o link no Chrome/Edge do celular, use “Adicionar à tela inicial” ou o botão “Instalar app”, quando aparecer.
4. Os dados ficam salvos apenas no navegador/dispositivo pelo localStorage.
5. Use “Gerar evolução” para criar o texto e “Copiar” para colar no prontuário.

Observação:
O app é uma ferramenta de registro e apoio. A interpretação clínica deve considerar o quadro do paciente, sinais vitais, restrições, dor, fadiga, nível de consciência e risco de queda.
